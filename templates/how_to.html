About This Chat Interface

How It Works

This is a chat that answers questions exclusively using available MCP tools.

How to Use

Type your question in the input field at the bottom. The AI will automatically determine which tools to call based on your question and provide answers based solely on the tool results.

What to Expect

  • The AI must call at least one tool for every question you ask
  • The AI never answers from its own "knowledge" — only uses tool results
  • If no tool can answer your question, you will see this response: "We don't have any internal tool to answer your question."

Structured Content

The chat interface has 5 types of outputs:

  • Assistant: What the AI has decided to respond with all the information.
  • Table: Raw data from the source (returned by the MCP).
  • Chart: An interactive visualization (returned by the MCP).
  • Foce: A messaged written by the tool developer that it is not processed by the LLM.
  • Source: A link to the source of the data used to provide the response.

Technical Details

The OKFN MCP Platform connects open public data to AI models using the Model Context Protocol (MCP). Its design is guided by two goals: accuracy, so answers are computed from official data rather than recalled from model training; and traceability, so every answer can link back to its source.

The platform consists of:

  • An MCP server that exposes open datasets as tools an AI can call.
  • A chat gateway that connects an OpenAI-compatible model to the server and renders tables, charts and source links directly from tool results.
  • Modular plugins, each scoped to a focused data domain, that describe their datasets and the questions they can answer.

The complete manual covers the system architecture, setup, plugin and dataset development, deployment and contributing: read the MCP Technical Documentation.

Source code is available in the MCP server repository and the chat interface repository.
